# 腾讯财经行情接入

## 请求与覆盖

根据项目指定的数据源，所有报价从 `https://qt.gtimg.cn/q=...` 获取，多个代码以逗号分隔。名称与拼音建议使用腾讯财经的 `smartbox.gtimg.cn/s3/`。客户端通过 HTTPS 读取文本记录并解析字段，无需页面抓取、浏览器或 API Key。[腾讯批量报价示例](https://qt.gtimg.cn/q=sh600519,sz000001,bj920002,hk00700,usAAPL,usIBM,usBTG) · [腾讯证券搜索示例](https://smartbox.gtimg.cn/s3/?v=2&t=all&q=aapl)

| 交易所 | 已验证查询 | 识别方法 |
| --- | --- | --- |
| 上海证券交易所 | sh600519 | sh 前缀与证券类型 |
| 深圳证券交易所 | sz000001 | sz 前缀与证券类型 |
| 北京证券交易所 | bj920002 | bj 前缀与证券类型 |
| 香港交易所 | hk00700、hk80700 | hk 前缀，同一发行人的不同币种柜台分别保存 |
| NASDAQ | usAAPL | 返回代码 AAPL.OQ |
| NYSE | usIBM、usBRK.B | IBM.N、BRK.B.N，股类代码中的点保留 |
| NYSE American | usBTG | BTG.AM |

证券列表支持股票和沪深场内 ETF。腾讯在搜索结果中将沪深 ETF 标为 `ETF` 或 `QDII-ETF`，例如 `sh513330` 的搜索类型为 `QDII-ETF`，行情类型为 `ETF`。个别冷门证券、停牌证券和新上市证券可能缺字段或暂时查不到。针对腾讯名称建议漏收的北交所股票，程序内置 2026-11-24 从腾讯 920 号段报价提取的 359 条代码和简称。维护时可运行 `python tools/update-bse-index.py` 更新目录。搜索仍支持以完整代码核实新标的。

## 报价字段

沪深京、香港和美国的指数记录使用腾讯的 `ZS` 类型。美股指数的目录代码和报价代码可能分别写作 `ndx` 和 `.NDX`，程序将二者识别为同一个 `usNDX`。内地指数使用与沪深京股票相同的成交额字段。香港和美国指数的成交额口径尚未核实，界面以横线显示。

`TencentParser` 用 GBK 解码记录，保留腾讯行情时间。以下字段以波浪号分隔后的零基索引表示，依据联网样本核对。供应方后续变更格式时需要重新验证。

| 字段 | 处理 |
| --- | --- |
| 1、2 | 证券简称、原始代码。在美国市场从原始代码的末段识别交易所。 |
| 3、4 | 现价、昨收。价格必须有效且大于零，据此计算涨跌额和涨跌幅。 |
| 30 | 行情时间。沪深京港按 UTC+8，美股按纽约时区转换，自动应用夏令时。 |
| 内地 35、37 | 优先读取 35 中“价格/成交量/成交额”的第三项原币金额。缺少该项时将 37 的万单位换算回原币。 |
| 香港、美国 37 | 原币成交额。使用报价中的 CNY、CNH、HKD、USD 标记；无法识别币种或金额时显示横线。 |

同一时刻查询 `hk00700` 和 `r_hk00700` 的样本时间相差约 15 分钟。程序采用普通 `hk` 档并标记“延时”。其他市场显示“快照”。公开端点可在无需付费凭据的条件下查询，未找到可确认固定报价延迟、商业授权、SLA 或正式配额的腾讯公开文档。商业展示、转售或再分发须另行核实授权及费用。

## 调度、缓存与异常

- 单个调度器读取自选股快照，每批最多 40 只。查询与搜索共用 HTTP 客户端，请求起始时间至少间隔一秒。此间隔是客户端的保守限速。
- 单次 HTTP 超时为 9 秒。超时、连接故障和特定 5xx 响应最多重试一次。遇到 429 或 503 遵守 Retry-After，缺少该响应头时至少退避 60 秒。下一轮定时刷新在上一轮结束后开始。
- 数据按证券键匹配；未知记录、缺值和时间倒退的记录不能替换有效缓存。单股失败时其他有效记录照常显示。只为变化的属性通知界面。
- 窗口隐藏、收纳或模块关闭时取消请求和等待。恢复展示立即调度一次，仍遵守服务端退避。缓存有独立行情时间，网络异常时可看到最后一笔有效值。
- 交易中比预期落后 5 分钟的普通快照，或落后 22 分钟的港股延时报价，会显示“已过期”。休市时与最近一次应有的交易时段比较。时间超前超过 5 分钟也会标记过期。
